# Registro de prompts (evidencia para la fase Construction)

La rubrica del proyecto final exige mostrar **2-3 prompts reales** y **al menos un
ejemplo de codigo que la IA genero mal y tuvimos que corregir**.

Eso NO se puede reconstruir de memoria el ultimo dia. Por eso:

## Regla del equipo

Cada vez que uses la IA para generar o arreglar algo de tu modulo, crea aqui un
archivo `NN-tu-nombre-tema.md` y pega:

1. El prompt **tal cual lo escribiste** (sin editarlo para que suene mejor).
2. Que devolvio la IA (resumen o el codigo, si es corto).
3. Que tuviste que cambiar y **por que**.
4. Si el error solo aparecio al desplegar, dilo: ese es el ejemplo mas valioso.

## Plantilla

```markdown
# [Tema] - [Tu nombre] - [Fecha]

## Prompt usado
(pegar aqui, literal)

## Que genero la IA
(codigo o resumen)

## Que corregi y por que
(el cambio + la razon)

## Aparecio en local o solo en produccion?
```
